## Cloudflare Pages
1. Create a GitHub repository and upload the contents of this folder.
2. In Cloudflare: Workers & Pages → Create application → Pages → Connect to Git.
3. Select the GitHub repository.
4. For a plain static HTML site, no framework is required. Keep the output directory empty / root as appropriate for your selected Pages setup.
5. Deploy the project.
6. Add `3dxtudio.com` under Custom Domains after the project is live.

## Local testing
Open `index.html` directly, or run any simple local HTTP server from this folder.
